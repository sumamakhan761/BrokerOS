## Overview

The mobile app is built with Expo 54 and Expo Router 6, targeting **Android only** (no iOS configuration). It's designed for field teams — pre-sales executives making cold calls, sales executives doing site visits, sourcing managers meeting brokers, and closing managers creating on-site bookings.

## Auto-Dialer Module

The auto-dialer is a **custom native Android module** that enables pre-sales executives to make sequential cold calls without manually dialing each number.

- Located at `modules/auto-dialer/` as a local npm package
- Referenced in `package.json` as `"auto-dialer": "file:modules/auto-dialer"`
- Bridged to JS via `hooks/useCallStatus.ts`
- **Do not `npm install` this** — it's a local file dependency

## Development

### Prerequisites

- Node.js ≥ 22
- pnpm ≥ 10
- Running backend (the mobile app connects to it via LAN IP)

### 1. Installation

```bash
cd mobile
pnpm install
```
*(Note: Do not `npm install` the `auto-dialer` module separately; it is linked locally).*

### 2. Environment Setup

You must configure your `mobile/.env` file properly before starting the Expo server.
```bash
cp .env.example .env
```

#### A. Backend API URL (CRITICAL)
Your phone or emulator cannot reach `localhost`. You must set `EXPO_PUBLIC_API_URL` to your machine's **LAN IP Address**.
- Windows: run `ipconfig` (look for IPv4 Address)
- Mac/Linux: run `ifconfig`

Update `mobile/.env`:
```env
EXPO_PUBLIC_API_URL="http://192.168.x.x:3333"
```

#### B. Google Maps (Required for Site Visits)
The mobile app relies on Google Maps natively for GPS verification of site visits and broker meetings.
1. Go to [Google Cloud Console](https://console.cloud.google.com/apis/credentials).
2. Enable the **Maps SDK for Android**.
3. Generate an API key.
4. **Important**: You must place this key in:
   - `mobile/.env` as `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY="your-key"`

### 3. Push Notifications & Expo Dashboard (CRITICAL)
To enable background push notifications and the auto-dialer sync, you must configure Firebase Cloud Messaging (FCM) and link it to your Expo account:

1. **Firebase Setup**:
   - Go to the [Firebase Console](https://console.firebase.google.com/) and create a project.
   - Add an Android App with the package name `com.anonymous.mobile` (from `app.json`).
   - Download the `google-services.json` file and place it in the root of the `mobile/` directory.

2. **Generate Google Service Account Key**:
   - In Firebase, go to Project Settings -> Service Accounts.
   - Click **Generate new private key**. This will download a `.json` file containing your Service Account credentials.

3. **Expo Dashboard Upload**:
   - Run `npx expo login` in your terminal to log into your Expo account.
   - Go to your [Expo Dashboard](https://expo.dev/) in the browser.
   - Select the `mobile` project.
   - Go to **Credentials** -> **Android** -> **Push Credentials**.
   - Click **Add FCM Server Key** (or Service Account Key) and upload the `.json` file you generated in step 2.

*Without this step, Expo cannot send push notifications to Android devices.*

### 4. Running the App (Two Options)

#### Option A: Android Emulator (Android Studio)
1. Open **Android Studio** and start your Virtual Device from the Device Manager.
2. Once booted, run:
   ```bash
   npx expo run:android
   ```

#### Option B: Physical Android Device
1. Enable **Developer Options** and **USB Debugging** on your Android phone.
2. Connect via USB and verify with `adb devices`.
3. Run:
   ```bash
   npx expo run:android
   ```

> **Warning:** Because this app uses custom native code (the Auto-Dialer), **it will NOT work in the standard Expo Go app from the Play Store**. You must use `npx expo run:android` which compiles a custom development app specifically for this project and installs it on your phone/emulator.

---

### Java Home (Windows Troubleshooting)

If your Android build fails with a "Java" or "JDK" error on Windows, you need to point your terminal to the Java version bundled with Android Studio.

Run this command directly in your PowerShell terminal **before** running `npx expo run:android`:

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
```

## Building for Distribution

### APK (for sideloading / GitHub Releases)

```bash
eas build --platform android --profile preview
# Download the .apk from the EAS dashboard
# Attach to a GitHub Release for users to download
```

### Internal Distribution (EAS)

The `eas.json` already has a `preview` profile with `"distribution": "internal"`:

```bash
eas build --platform android --profile preview
# Generates a shareable link — anyone with the link can install
```

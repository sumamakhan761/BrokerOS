# Security Policy

**Do not file public issues for private security reports**

If you believe you've found a security issue in BrokerOS, report it privately first.

## Reporting a Vulnerability

For issues that don't fit a specific repo, or if you're unsure, email  **[sumamakhan800@gmail.com](mailto:sumamakhan800@gmail.com)** and we'll route it.

1. **Title** 
2. **Description**
3. **Steps to reproduce** 
4. **Potential impact** 
5. **Affected component** 
6. **Suggested fix**
